# Ame の使い方

[English](user-guide.md) · [简体中文](user-guide.zh-Hans.md)

## フォルダーとモデルの準備

「すべての写真」でフォルダー見出しの追加ボタンを押し、画像のあるフォルダーを選びます。
見つかった画像から順に表示されます。フォルダーメニューでは更新と同期の設定ができます。
ドライブやクラウドのフォルダーに接続できない場合は、接続を戻してから更新してください。
クラウド上の画像は解析前にローカルで利用できる状態にする必要があります。原本の自動ダウンロードは行いません。

スマートアルバムと言葉による検索には解析モデルが必要です。画面の案内に従って準備し、
ダウンロードが失敗した場合は通知から再開できます。分類中も画像を閲覧できます。
GPU アクセラレーションは設定のスマートアルバム項目で変更できます。

## インストールと更新

MSI 版にはモデルとバックグラウンド更新サービスが含まれ、インストールと MSI 更新には管理者権限が必要です。
ポータブル版は ZIP 全体を展開して実行し、必要なモデルを後から取得します。Windows サービスは追加しません。
データの保存先は設定のストレージ項目で確認できます。すべてのデータがプログラムと同じフォルダーに入るわけではありません。

設定の「このアプリについて」から更新を確認してダウンロードし、再起動して適用します。
自動確認・ダウンロードと更新チャネルを選べます。プレビューチャネルには Alpha、Beta、RC が含まれます。
失敗した場合は通知の操作を使うか、[リリースページ](https://github.com/Cedarflake/Cedarflake-Ame/releases)から取得してください。
手動更新では Ame を閉じ、新しい MSI を実行するか、ポータブル ZIP を別のフォルダーに完全に展開します。

## バックアップと復元

設定の整理記録から、お気に入り、アルバム、整理の判断をエクスポートできます。
画像や Ame データとは別のフォルダーに保存してください。復元ではファイルを選び、内容を確認して適用します。
画像の原本はこのバックアップに含まれないため、別途バックアップしてください。

コピーや移動が中断した場合はファイル操作記録を開き、その操作に用意された再開手順を使います。
通常の削除は Windows のごみ箱から復元できます。完全削除はごみ箱に入りません。

## 診断情報を共有する

設定の「このアプリについて」→ 診断情報からエクスポートし、ZIP の保存先を選びます。
完了通知から保存先を開けます。起動に失敗した画面でも診断情報をエクスポートできます。
コピー操作では短い要約をコピーします。保存できない場合は保存先を選び直すか、表示された再試行を使います。

ZIP にはアプリとシステムのバージョン、取得できた処理・モデルの状態、最近のエラーコードが入ります。
画像、ライブラリの記録、認証情報、個人のパスは含みません。共有するまでは PC 内に保存されます。
[不具合報告](https://github.com/Cedarflake/Cedarflake-Ame/issues)に添付するときは、再現手順と発生時刻も記載してください。
スクリーンショットを添える場合は、個人情報が写っていないか別途確認してください。
