Cedarflake Ame 的首个 Beta 预发布版本，面向 Windows 11 x64。

## 本次更新

- **相册按年份整理**：将相册中的实际文件移入“目标文件夹／相册名／年份”。沿用图库日期，优先使用拍摄时间，其次使用文件创建时间和修改时间；操作记录支持查看结果和继续未完成的移动。
- **图片复制**：在图片查看器中将当前图片复制到剪贴板，方便粘贴到其他应用；复制结果包含当前的查看旋转。
- **图库筛选与去重**：在原有图片墙和时间轴中筛选重复组、相似组；成员托盘支持预览、选择、设置首选和删除。改进语义搜索的范围查询，去重页面增加清晰的组类型和严格程度选项。
- **Material 宽屏布局**：重新组织导航、侧栏、搜索和设置；调整去重卡片、菜单和选择反馈，改善图片预览、缩略图栏和侧栏切换的过渡。
- **大图库响应**：减少扫描过程的数据库写入，改善图库启动、分类切换、时间轴拖动和后台更新时的响应，完善中断恢复及文件移动后的路径跟踪。
- **应用更新**：在设置中检查、下载更新并查看更新说明，支持自动检查和自动下载选项；下载完成后可选择重启更新。安装版通过 Windows Installer 更新，便携版直接更新应用目录。
- **语言与诊断**：支持简体中文、English 和日本語；可从设置或启动失败界面导出诊断信息，并提供使用和恢复指南。
- **安装与升级**：补齐应用、图片分析运行时和服务需要的运行库，完善 Alpha 3 升级、失败回滚及图库兼容处理。

## 下载与升级

- **安装版**：下载 `Cedarflake-Ame-v0.1.0-beta.1-windows-x64.msi`。包含图片分析模型、运行时和图库更新服务；安装和更新需要管理员权限，支持修复和卸载。
- **便携版**：下载 `Cedarflake-Ame-v0.1.0-beta.1-windows-x64-portable.zip`，完整解压后运行 `Cedarflake-Ame/Cedarflake Ame.exe`。图片分析模型在首次使用时下载。

从 Alpha 版升级时，先关闭 Ame，再运行新版 MSI；便携版请解压到新的目录，并从新版启动器打开。收藏、相册和整理记录会随图库升级保留。升级后的图库不支持旧 Alpha 版直接打开。

`CedarflakeAme-0.1.0-beta.1-full.nupkg` 和 `ame-update-windows-x64.json` 用于应用内更新，首次使用请选择 MSI 或 ZIP。

本版本未签名，Windows 可能显示未知发布者提示。

## 已知限制

- 分类、语义搜索和相似图片结果可能存在误匹配或漏匹配。
- 首次打开图片或长时间调整窗口尺寸时，仍可能出现短暂卡顿；低配置设备和百万级图库尚未完成完整体验验证。
- 仅存于云端的图片需要先在云盘中下载，Ame 不会自动下载这些原图。
- Windows 回收站按路径处理文件；其他程序在最后一次核验后立即替换同名文件时，仍可能回收替换后的文件。
- 本次发布提供 Windows 11 x64 包；ARM64 仍为独立的预览构建。
