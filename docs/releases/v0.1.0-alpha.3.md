Cedarflake Ame 的第三个 Alpha 预发布版本，面向 Windows 11 x64。后续 R10 将进入 Beta 阶段。

## 本次更新

- **文件整理与恢复**：支持复制、移动、重命名、移入 Windows 回收站和明确选择后的永久删除；可查看操作记录、处理结果和继续未完成的整理。
- **重复与相似图片清理**：支持在组内、选中的组和整个列表中清理多余图片，保留已选择的图片；未手动选择时保留自动选出的代表图片。删除前显示实际图片数量并要求确认。
- **智能相册与整理响应**：缩短分类、去重列表和整理模式的等待，优先响应当前浏览操作；无关的后台更新不再打断当前图片的收藏和相册操作，保留自动新增分类。
- **看图与动效**：卡片平滑展开到预览，关闭时缩回原卡片；改善画质切换和圆角衔接。缩略图栏以覆盖方式展开、收起，不再挤压主图高度。
- **界面反馈**：统一加载动画、异常弹窗和设置操作，减少短暂加载闪烁；改进侧栏展开、选择反馈、时间轴位置保持与日期显示。

## 下载与使用

- **安装版**：下载 `Cedarflake-Ame-v0.1.0-alpha.3-windows-x64.msi`。包含图片分析模型、运行时和图库更新服务；安装需要管理员权限，支持修复和卸载，卸载保留图库与个人数据。
- **便携版**：下载 `Cedarflake-Ame-v0.1.0-alpha.3-windows-x64-portable.zip`，完整解压后运行 `Cedarflake-Ame/cedarflake_ame.exe`。不安装系统服务，图片分析模型在首次使用时另行下载。

从旧版更新时，请先正常关闭 Ame，再安装新版或将便携包解压到新的目录；不要混用两个版本的运行文件。
两个包均由 GitHub Actions 从同一提交构建和验证。仍为未签名版本，Windows 可能显示未知发布者提示，暂不提供自动更新。

## 已知范围

本版本仍处于 Alpha 阶段。大图库分类切换和文件操作后的图库更新仍可能有可见等待；分类、语义搜索和相似图片结果可能存在误匹配或漏匹配。

浏览、分析与观看旋转不会修改原图，也不会自动下载仅存于云端的原图。文件操作只在确认后执行；Windows 回收按路径处理，其他程序在最终核验后瞬间替换同名文件时，仍可能回收替换后的文件。
