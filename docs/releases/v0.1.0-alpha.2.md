Cedarflake Ame 的第二个 Alpha 预发布版本，面向 Windows 11 x64。

## 本次更新

- **语义搜索与找相似图**：在图库中按描述查找图片，也可以从当前图片查找相关内容；结果保留在当前图库视图中。
- **GPU 图片分析**：接入默认启用的 GPU 加速，可在设置中关闭，继续使用 CPU 分析。
- **组合筛选**：支持多选文件格式，并结合日期、图片尺寸、文件大小和相机信息筛选；更多筛选使用统一的底部托盘。
- **相册与看图**：创建相册时可选择图标，也可通过右键菜单更改；看图新增旋转观看方向的按钮，不改动原图文件。
- **图库导航与加载**：改进等高和网格布局中的时间轴拖动、远处卡片占位、分类切换和加载后位置保持，减少重复查询；智能相册补齐加载反馈。
- **组件与许可**：迁移到独立维护的 Material 组件库；项目采用 Apache License 2.0，第三方组件与模型保留各自许可。

## 下载与使用

- **安装版**：下载 `Cedarflake-Ame-v0.1.0-alpha.2-windows-x64.msi`。包含图片分析模型、运行时和图库更新服务；安装需要管理员权限，支持修复和卸载，卸载保留图库与个人数据。
- **便携版**：下载 `Cedarflake-Ame-v0.1.0-alpha.2-windows-x64-portable.zip`，完整解压后运行 `Cedarflake-Ame/cedarflake_ame.exe`。不安装系统服务，图片分析模型在首次使用时另行下载。

从 Alpha 1 更新时，请先正常关闭 Ame，再安装新版或将便携包解压到新的目录；不要混用两个版本的运行文件。
本次两个包均由 GitHub Actions 从同一提交构建和验证。仍为未签名版本，Windows 可能显示未知发布者提示，暂不提供自动更新。

## 已知范围

本版本仍处于 Alpha 阶段。首次启动和大图库查询仍可能有可见等待；分类、语义搜索和相似图片结果可能存在误匹配或漏匹配。
文件移动、重命名和删除流程尚未提供。浏览、分析与观看旋转不会修改原图，也不会自动下载仅存于云端的原图。

完整改动：[Alpha 1 → Alpha 2](https://github.com/Cedarflake/Cedarflake-Ame/compare/v0.1.0-alpha.1...v0.1.0-alpha.2)。
