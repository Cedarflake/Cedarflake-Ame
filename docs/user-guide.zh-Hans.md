# Ame 使用指南

[English](user-guide.md) · [日本語](user-guide.ja.md)

## 添加图片和准备模型

在“所有图片”的“文件夹”标题旁点击添加按钮，选择已有的图片文件夹。扫描过程中会陆续显示图片。
文件夹菜单提供“更新图库”和同步设置。磁盘或云盘目录暂时不可用时，重新连接后再更新。
云端图片需要先在本地可用才能分析，Ame 不会自动下载原图。

智能相册和语义搜索需要图片分析模型，按界面提示准备即可；下载失败后，可以从提示中继续。
分类在后台进行，期间可以浏览图片。“设置 → 智能相册”可以调整 GPU 加速。

## 安装版、便携版和更新

MSI 安装版包含模型和后台图库更新服务，安装与 MSI 更新需要管理员权限。
便携 ZIP 完整解压后即可运行，需要模型时再下载，不安装 Windows 服务。
数据的实际位置可以在“设置 → 存储”查看，程序放在便携目录中不意味着所有数据都在该目录内。

在“设置 → 关于”检查更新，下载后点击“重启并更新”。更新设置可选择自动检查、自动下载和更新渠道。
预览版渠道包含 Alpha、Beta 和 RC。更新失败时，使用提示中的恢复操作，或从
[发布页面](https://github.com/Cedarflake/Cedarflake-Ame/releases)下载完整包。
手动更新前关闭 Ame；安装版运行新版 MSI，便携版将完整 ZIP 解压到新文件夹后启动。

## 备份和恢复

“设置 → 整理记录 → 导出”用于备份收藏、相册和整理决定。请将备份保存在图片目录和 Ame 数据目录之外。
通过“恢复整理记录”选择备份，检查后确认恢复。整理记录备份不包含原图片，原图片需要单独备份。
图库数据和缩略图的位置可以在“设置 → 存储”查看。

复制、移动中断后，打开“文件操作记录”查看该次操作，按其中提供的操作继续处理。
普通删除的文件可以到 Windows 回收站还原；永久删除不经过回收站。

## 提供诊断信息

在“设置 → 关于 → 诊断信息”点击“导出”，选择 ZIP 的保存位置。完成提示可以打开保存位置。
Ame 无法启动时，失败页面也提供“导出诊断信息”；“复制诊断信息”会复制简短摘要。
保存失败时重新选择位置，或使用提示中提供的“重试”。

诊断包包含可阅读的摘要和结构化运行信息，包括应用、系统和 Flutter 版本、CPU、内存、显卡与驱动、
显示缩放、可获取的任务和模型状态、近期错误码。
不包含图片、图库记录、凭据和个人路径。它保存在本机，由你决定是否分享。
提交[问题反馈](https://github.com/Cedarflake/Cedarflake-Ame/issues)时，附上诊断包、触发步骤和大致时间。
另外附加的截图请单独检查是否包含个人信息。
